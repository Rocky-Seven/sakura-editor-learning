# sakura-editor-learning

ブログ「My Studies：学びを始めよう」の連載「初心者SE向け サクラエディタの活用術」で使う、練習用のサンプルファイルである。

## サンプルファイルの入手方法

1. このリポジトリのページで、緑色の「Code」ボタンを押す
2. 「Download ZIP」を選ぶ
3. ダウンロードしたZIPを右クリックして「すべて展開」を選び、展開先をデスクトップにする
4. 展開されたフォルダの中の sample フォルダに、サンプルファイルが入っている

## サンプルファイル（`sample/`）

| ファイル | 内容 |
| :--- | :--- |
| **app.log** | 29行のシステムログ（ERRORが3件、WARNが2件含まれる） |
| **config.ini** | 設定ファイル |
| **main.c** | C言語のサンプル（ネストした括弧あり） |
| **util.c / util.h** | main.c から呼ばれる関数の定義 |
| **sample.txt** | 見出し付きのテキスト（第2回のアウトライン解析用） |
| **index.html** | 簡単なHTML（第2回のアウトライン解析用） |

## 連載の構成
```
sakura-editor-learning/
├── README.md
└── sample/
    ├── app.log
    ├── config.ini
    ├── main.c
    ├── util.c
    ├── util.h
    ├── sample.txt
    └── index.html
```

| 回 | テーマ | 主な機能 |
|---|---|---|
| 第1回 | 探す編 | ジャンプ、Grep、ブックマーク |
| 第2回 | 読む・編集する編 | アウトライン解析、矩形選択、正規表現 |
| 第3回 | 効率化編 | キーマクロ、DIFF、各種設定 |

## 注意事項

- すべて中身を読めるテキストファイルである。実行ファイルは含まれていない
- Cファイルは、サクラエディタで開いて検索や移動を試すための素材である。コンパイルや実行はしないでください。（仮に実行しても画面に文字を表示するだけである）
- 第2回で `app.log` に置換を試す場合は、先にファイルをコピーしてバックアップを取ること。元に戻したいときは、このリポジトリから取得し直せばよい
- ファイルの文字コードはUTF-8である。文字化けする場合は、サクラエディタで文字コードを指定して開き直すこと
